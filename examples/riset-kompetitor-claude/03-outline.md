# WGY-O — Outline (lite): Riset kompetitor pakai Claude

Sources: 02-research.md (CL-A Claude in Chrome, CL-B web search, META-AL Ad Library help + live walkthrough) and 05-stepcheck.md (USER walkthrough A to E).

HERO
  Eyebrow: Free Guide · Riset Kompetitor × Claude
  Title: Riset 3 kompetitor dan iklan Meta mereka dalam 45 menit, pakai Claude gratis
  Subtitle: Harga, klaim, dan iklan yang sedang mereka jalankan, dirangkum jadi satu Google Sheet plus 3 ide yang bisa langsung kamu tes. 100% tool gratis, tanpa extension berbayar.
  Chips: 30–45 menit · Pemula · Biaya tool: Rp0

RESULT (one box)
  - Competitor Snapshot di Google Sheets untuk 3 kompetitor
  - Iklan aktif mereka di Meta: angle, tanggal mulai tayang, arah iklan
  - 3 celah dan 3 ide tes untuk brand kamu
  Success check: setiap baris punya link sumber dan tanggal cek, dan setiap ide tes menyebut iklan yang jadi dasarnya.
  Note: Claude in Chrome (Pro) is optional; this guide runs on the Free plan.

STEPS (one section, no phases)
  1. Pilih 3 kompetitor dan catat website + nama Page-nya. Tip: kompetitor yang jualannya mirip, bukan yang paling besar.
  2. Nyalakan Web search dan tarik data website (Prompt A). Source: CL-B (DOC) + USER A/B. Pitfalls: USD dari situs /en (USER B); toko Shopee tidak terbaca (USER C) → copy-paste.
  3. Cari kompetitor di Meta Ad Library dan pilih advertiser yang benar. Source: META-AL (DOC) + LIVE walkthrough. Pitfalls: Ad category dulu; keyword berisik & reseller; ad blocker.
  4. Copy teks halaman iklan dan paste ke Claude (Prompt B). Source: USER D (link tidak terbaca). Pitfall: jangan paste link; label "petunjuk, bukan bukti" untuk iklan yang lama jalan.
  5. Susun Competitor Snapshot + 3 ide tes, paste ke Sheets (Prompt C). Source: USER E. Pitfall: copy tabelnya saja.
  CHECKPOINT after step 5. Ladder point: soft aside after the checkpoint.

PROMPTS
  A. Data website (per kompetitor)
  B. Analisis iklan dari teks Ad Library (per kompetitor)
  C. Competitor Snapshot + 3 celah + 3 ide tes

QUICK FIXES (top 3)
  1. Claude bilang tidak bisa membaca halaman (Shopee, Ad Library, situs JavaScript) → copy-paste teks atau upload screenshot.
  2. Hasil Ad Library campur brand lain / reseller → pilih di Advertisers, cek followers dan handle resmi.
  3. Kena batas pemakaian plan Free → satu kompetitor per pesan, matikan Web search saat paste teks, tunggu reset 5 jam.

CLOSING
  Wall (turning ideas into tested creative weekly), bridge (Gwenchana Meta Ads, Starter), not-for (belum beriklan / masih validasi produk), mention of the follow-up emails, CTA.
