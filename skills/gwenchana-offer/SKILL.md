# Gwenchana Offer Ladder

## Service lines

| Line | Service |
|---|---|
| `seo-geo` | SEO/GEO: search rankings plus visibility in AI answers (ChatGPT, Gemini, Perplexity, Google AI Overviews) |
| `meta-ads` | Performance Ads: Meta Ads (Facebook and Instagram) |
| `google-ads` | Performance Ads: Google Ads |

This file holds only the service names. Scope, deliverables, price, minimum contract, case studies, results, and the CTA destination come from the user in the session. If one is needed and missing, ask. Never write a contact number, email, or booking link into this repo.

## Free guide ideas that ladder well

A good freebie gives a finished result the reader can check, using free tools only.

**seo-geo**
- Set up Google Search Console, submit a sitemap, and pull "quick win" queries (average position 8 to 20) into a sheet.
- Rewrite title tags and meta descriptions for the 10 pages with the most impressions and lowest CTR in Search Console.
- Manual AI visibility check: a fixed prompt list run in ChatGPT, Gemini, and Perplexity, logged in a scoring sheet.

**meta-ads**
- Install the Meta Pixel and verify events in Events Manager (Test Events).
- Competitor creative research with Meta Ad Library, logged in an angle and hook swipe file.
- First campaign structure for a small budget: one campaign, clear objective, naming convention.

**google-ads**
- Keyword research with Google Keyword Planner into a grouped keyword list.
- Conversion tracking from GA4 key events imported into Google Ads, verified with Tag Assistant.
- A starter negative keyword list built from the search terms report.

## The wall: what the reader hits after finishing

The wall is the premium bridge. Name it honestly. Never create it by holding back steps.

| Line | Typical walls |
|---|---|
| `seo-geo` | Fixes need ongoing content production every month. Technical issues go beyond settings (speed, indexing, site structure). Results compound over months, so consistency beats one sprint. Tracking AI visibility across many prompts by hand does not scale. |
| `meta-ads` | Creative testing needs a steady supply of new ads. Scaling budget without the cost per result collapsing. Server-side tracking (Conversions API) and attribution gaps. |
| `google-ads` | Weekly search term mining and bid strategy tuning. Budget pacing across campaigns. Performance Max and conversion value setup. |

## Cost honesty

- Tools can be free while ads still cost money. Every ads guide says in its promise that the reader's ad budget is separate from the free tools.
- Never call a step free when it needs a paid plan, a trial that asks for a card, or ad spend.

## Claims

- No guaranteed rankings, traffic, AI citations, ROAS, leads, or revenue.
- Case study numbers only when the user supplies them for this guide.
- Always include who premium is **not** for (for example: "Kalau budget iklanmu masih di bawah X per bulan, jalankan guide ini dulu"). Get the real threshold from the user or leave the criterion qualitative.
